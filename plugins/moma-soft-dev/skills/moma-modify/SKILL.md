# /moma-modify —— 需求调整

调整已有需求，同步更新文档和代码。

> 共享约定见 `../moma-soft-dev/references/common-conventions.md`，编码通用约束必须严格遵守。

## 上下文范围

加载用户输入 + `docs/01-项目概要.md` + `docs/02-产品需求文档.md` + 受影响的下游文档（03~07 中相关部分） + `docs/08-变更日志.md` + 与变更相关的现有代码。不加载模板文件，不加载无关文档章节和代码。

## 步骤

1. 结合 01 和 02 文档，分析用户输入中哪些需求需要调整。
2. 更新阶段1文档，并同步更新受影响的下游文档（03~07）。如果下游文档已存在，必须逐一检查并更新；如果尚未生成则跳过。
3. 根据变更需求进行代码变更，遵循 `⚠️ AI 约束`。
4. 在 `docs/08-变更日志.md` 中记录本次变更（不存在则创建）。
5. 如果项目有版本控制，生成 `modify: <变更简述>` 格式的提交。
