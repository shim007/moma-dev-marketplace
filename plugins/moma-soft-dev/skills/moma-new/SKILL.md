# /moma-new —— 功能新增

增加原有需求中未描述的全新功能。执行流程遵循 `${CLAUDE_PLUGIN_ROOT}/skills/moma-soft-dev/references/change-workflow.md` 的通用变更流程，本文件只声明本指令区别于其他变更指令的判定点。

> 共享约定见 `${CLAUDE_PLUGIN_ROOT}/skills/moma-soft-dev/references/common-conventions.md`，编码通用约束必须严格遵守。

## 上下文范围

加载用户输入 + 01/02 文档（定位新功能归属模块） + 需要扩展的下游文档 + 变更日志 + 相关模块代码。不加载模板和无关内容。

## 本指令判定点

- **变更类型判定：** 新增**原需求未包含**的功能——区别于 `/moma-modify`（调整已有需求）与 `/moma-optimize`（细化行为边界）。
- **归属与扩展分析：** 步骤2 中除识别功能本身外，还需明确：归属的现有模块或需新建的模块；对 04 数据模型、05 接口的**新增项**（尽量新增表/接口而非改动既有结构，降低对已有功能的影响）；07 中需要补充的测试场景。

## 步骤

按 `change-workflow.md` 的步骤1~7 顺序执行，本指令的差异点：

- 步骤2 意图分析：按上文"归属与扩展分析"执行；
- 步骤6 提交前缀：`feat: <功能简述>`。
