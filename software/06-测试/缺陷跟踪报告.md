## 2 缺陷分类标准

### 2.1 严重级别定义

| 级别 | 名称 | 定义 | 典型示例 |
| ---- | ---- | ---- | -------- |
| S1 | 致命 | 导致系统崩溃、数据丢失或核心功能完全不可用，无法通过任何手段规避，必须立即修复 | 系统启动失败无法使用；核心数据被错误删除且无法恢复；服务器频繁宕机；资金/金额计算出现严重错误 |
| S2 | 严重 | 主要功能异常或数据错误，严重影响业务流程的正常运行，存在临时规避方案但代价较大 | 核心业务流程中断无法走通；关键报表数据不正确；用户无法完成注册或登录；权限控制失效导致越权访问 |
| S3 | 一般 | 次要功能缺陷或界面显示异常，不影响主要业务操作，有简单的规避方案 | 非核心功能异常但不影响主流程；界面排版/布局错误；提示信息不准确或不友好；查询条件组合异常 |
| S4 | 轻微 | 建议性问题或界面美观性问题，对功能和用户体验影响极小 | 错别字、标点符号错误；颜色与设计稿细微差异；对齐不整齐；建议性的用户体验优化 |

### 2.2 优先级定义

| 级别 | 名称 | 定义 | 修复时限 |
| ---- | ---- | ---- | -------- |
| P1 | 紧急 | 阻塞测试进度或影响生产环境，必须立即修复 | {{P1修复时限}}（如：4小时内） |
| P2 | 高 | 影响主要功能，必须在当前迭代/版本中修复 | {{P2修复时限}}（如：1个工作日内） |
| P3 | 中 | 影响次要功能，应在发布前修复 | {{P3修复时限}}（如：3个工作日内） |
| P4 | 低 | 优化建议类，可在后续版本中修复 | 下一版本 |

### 2.3 缺陷类型分类

| 类型代码 | 类型名称 | 说明 |
| -------- | -------- | ---- |
| FUN | 功能缺陷 | 功能实现与需求不符，业务逻辑错误 |
| UI | 界面缺陷 | 界面显示异常、布局错误、样式不一致 |
| PERF | 性能缺陷 | 响应超时、资源泄漏、吞吐量不达标 |
| SEC | 安全缺陷 | 安全漏洞、权限绕过、数据泄露 |
| COMP | 兼容性缺陷 | 在特定浏览器、操作系统或设备上出现的问题 |
| DATA | 数据缺陷 | 数据计算错误、数据丢失、数据不一致 |
| DOC | 文档缺陷 | 用户手册、帮助文档中的错误 |
| OTHER | 其他 | 不属于以上分类的缺陷 |

### 2.4 缺陷状态流转

```
┌──────┐    确认     ┌──────┐    分配     ┌──────┐
│ 新建  │ ────────→ │ 确认  │ ────────→ │ 分配  │
└──────┘           └──────┘           └──────┘
    │                   │                   │
    │ 拒绝              │ 延期              │ 修复中
    ↓                   ↓                   ↓
┌──────┐          ┌──────┐          ┌───────┐
│ 已拒绝 │         │ 延期  │          │ 修复中 │
└──────┘          └──────┘          └───────┘
    │                                    │
    │ 复议                               │ 提交修复
    ↓                                    ↓
┌──────┐                          ┌──────┐
│ 确认  │                          │ 已修复 │
└──────┘                          └──────┘
                                       │
                                       │ 验证
                                       ↓
                                 ┌──────────┐
                            ┌──→ │  已关闭   │
                  验证通过 │    └──────────┘
                            │
                     ┌──────┐
                     │ 验证中 │
                     └──────┘
                            │
                  验证失败 │    ┌──────────┐
                            └──→ │ 重新打开  │ ──→ 分配
                                 └──────────┘
```

**状态说明：**

| 状态 | 英文 | 说明 | 操作人 |
| ---- | ---- | ---- | ------ |
| 新建 | New | 测试人员发现缺陷并提交 | 测试人员 |
| 确认 | Confirmed | 确认为有效缺陷 | 测试负责人/开发负责人 |
| 分配 | Assigned | 缺陷已分配给指定开发人员 | 开发负责人 |
| 修复中 | Fixing | 开发人员正在修复 | 开发人员 |
| 已修复 | Fixed | 开发人员已完成修复 | 开发人员 |
| 验证中 | Verifying | 测试人员正在验证修复结果 | 测试人员 |
| 已关闭 | Closed | 验证通过，缺陷已解决 | 测试人员 |
| 重新打开 | Reopened | 验证未通过，缺陷未真正修复 | 测试人员 |
| 已拒绝 | Rejected | 经评估确认非缺陷 | 开发负责人 |
| 延期 | Deferred | 经评估同意延期至后续版本修复 | 项目经理 |
