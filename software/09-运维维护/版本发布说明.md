### 1.2 版本命名规范

本项目遵循语义化版本规范（Semantic Versioning）：

- **主版本号（Major）**：存在不兼容的 API 变更或重大架构调整
- **次版本号（Minor）**：新增向下兼容的功能特性
- **修订号（Patch）**：向下兼容的问题修复
- **热修复（Hotfix）**：基于已发布版本的紧急修复，版本号格式为 X.Y.Z-hotfix.N

### 1.3 发布流程概要

```
代码冻结 → 构建打包 → 测试环境部署 → 回归测试 → 预发布环境部署 → 验收测试 → 生产发布 → 发布验证 → 发布公告
```

### 1.4 发布审批要求

| 发布类型 | 审批人 | 提前通知时间 | 回归测试要求 |
|----------|--------|-------------|-------------|
| 重大版本（Major） | {{审批人}} | ≥ 5 个工作日 | 全量回归 |
| 功能版本（Minor） | {{审批人}} | ≥ 3 个工作日 | 核心功能回归 |
