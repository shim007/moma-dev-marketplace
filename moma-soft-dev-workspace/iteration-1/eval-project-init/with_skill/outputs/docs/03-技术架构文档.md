## 2. 系统架构概览

### 2.1 架构风格

采用**前后端分离**的单体架构。前端使用 React SPA，后端使用 Spring Boot 单体应用，通过 RESTful API + WebSocket 通信。

**选择理由：**
- 项目为单校使用的中小型应用，单体架构足以应对初期业务规模
- 前后端分离便于独立开发和部署
- Spring Boot 单体架构开发效率高，运维成本低
- 后续如需扩展可平滑演进为微服务架构

### 2.3 分层结构

| 层级 | 职责 | 技术实现 |
|------|------|----------|
| 表示层(Presentation) | 用户界面渲染、用户交互、路由管理 | React + React Router + Axios |
| 接口层(Controller) | 接收请求、参数校验、响应封装 | Spring MVC REST Controller |
| 业务逻辑层(Service) | 核心业务逻辑处理、事务管理 | Spring Service + Spring Transaction |
| 数据访问层(Repository) | 数据库 CRUD 操作、数据映射 | Spring Data JPA |
| 数据存储层(Storage) | 数据持久化 | MySQL + Redis + 本地文件系统 |

## 6. 关键技术方案

### 6.1 认证与授权方案

- **认证方式：** JWT (JSON Web Token) 无状态认证
- **Token 生成：** 用户登录成功后由服务端生成，包含用户 ID 和角色信息
- **Token 有效期：** Access Token 2小时，Refresh Token 7天
- **Token 存储：** 前端存储在 localStorage，API 请求通过 Authorization Header 携带
- **权限控制：** 基于 Spring Security，使用自定义注解标注接口权限
  - 未认证用户：仅可访问公开接口（商品浏览、搜索、登录、注册）
  - 已认证用户：可访问所有业务接口
- **密码安全：** 使用 BCrypt 加盐哈希，强度因子 10

### 6.2 数据存储方案

- **主数据库：** MySQL 8.0，存储所有业务数据
- **缓存层：** Redis 用于热点商品缓存、用户会话信息、聊天在线状态
- **文件存储：** 商品图片和用户头像存储在本地文件系统的 `uploads/` 目录，通过静态资源映射提供访问
- **数据库连接池：** HikariCP（Spring Boot 默认）

### 6.3 错误处理方案

- **全局异常处理：** 使用 `@RestControllerAdvice` 统一捕获异常
- **业务异常：** 自定义 `BusinessException` 类，包含错误码和错误消息
- **参数校验异常：** 使用 Bean Validation 注解，校验失败返回 400
- **日志记录：** 使用 SLF4J + Logback，按级别输出到控制台和文件
- **前端错误处理：** Axios 拦截器统一处理 HTTP 错误，401 自动跳转登录页

### 6.4 缓存策略

- **商品列表缓存：** 首页热门商品列表缓存 5 分钟，新增/编辑/删除商品时清除缓存
- **用户信息缓存：** 用户基本信息缓存 30 分钟，修改信息时清除
- **在线状态：** Redis 存储用户 WebSocket 连接状态，心跳超时 30 秒自动标记离线

### 6.5 消息通信方案

- **通信协议：** WebSocket + STOMP 协议
- **连接管理：** 用户登录后建立 WebSocket 连接，携带 JWT Token 认证
- **消息路由：** 使用 STOMP 目的地前缀 `/app` 发送消息，`/user/queue` 接收私人消息
- **离线消息：** 消息持久化到 MySQL，用户上线后从数据库拉取未读消息
- **心跳机制：** 客户端每 10 秒发送心跳，服务端 20 秒无心跳判定断线

### 6.6 文件存储方案

- **存储位置：** 服务端本地文件系统 `{app.root}/uploads/` 目录
- **目录结构：** `uploads/products/{yyyy}/{MM}/{dd}/{uuid}.{ext}` 和 `uploads/avatars/{userId}/{uuid}.{ext}`
- **访问方式：** 通过 Spring 静态资源映射 `/files/**` 提供 HTTP 访问
- **上传限制：** 单文件 ≤ 5MB，仅允许 JPG/PNG/WEBP 格式
- **文件命名：** 使用 UUID 重命名，避免文件名冲突和路径遍历攻击
