## 2. 功能需求

### 2.1 用户管理

**模块概述：** 提供用户注册、登录、校园邮箱认证及个人中心功能。

**用户故事：**

| 编号 | 角色 | 行为 | 目的 |
|------|------|------|------|
| US-01-01 | 作为学生 | 我希望用校园邮箱注册账号 | 以便使用平台进行二手交易 |
| US-01-02 | 作为学生 | 我希望管理个人资料和交易记录 | 以便追踪我的买卖历史 |

**功能详细描述：**
- 支持校园邮箱注册，发送验证码完成验证
- 登录支持密码登录
- 个人中心展示已发布商品、交易记录、信用评分

**AI 实现边界：**
- ✅ 必须实现：邮箱注册、登录、个人中心基本信息展示
- ❌ 不得实现：第三方社交登录、手机号登录
- ⚠️ 需确认后实现：密码找回功能

**验收条件（AC）：**
- [ ] AC-1：用户可使用校园邮箱完成注册
- [ ] AC-2：注册用户可正常登录
- [ ] AC-3：个人中心展示基本信息和交易记录

**模块概述：** 用户可发布、编辑、上下架二手商品。

**用户故事：**

| 编号 | 角色 | 行为 | 目的 |

| US-02-01 | 作为卖家 | 我希望发布闲置物品信息 | 以便找到买家出售物品 |
| US-02-02 | 作为卖家 | 我希望管理已发布的商品 | 以便随时更新或下架商品 |

**功能详细描述：**

- 支持编辑已发布商品信息

### 2.7 拼团购买

**模块概述：** 允许多个用户一起拼团购买同一商品，达到最低拼团人数后以折扣价成交。卖家在发布商品时可设置拼团选项，买家可发起或加入已有拼团。

**用户故事：**

| 编号 | 角色 | 行为 | 目的 |
|------|------|------|------|
| US-07-01 | 作为卖家 | 我希望为商品设置拼团价和最低人数 | 以便通过拼团方式快速出货多件同类商品 |
| US-07-02 | 作为买家 | 我希望发起一个拼团 | 以便召集其他人一起以折扣价购买 |
| US-07-03 | 作为买家 | 我希望加入已有的拼团 | 以便以更低的价格购买商品 |
| US-07-04 | 作为买家 | 我希望查看拼团进度 | 以便了解还差几人成团 |

**功能详细描述：**

**拼团发起流程：**
1. 卖家在发布/编辑商品时，可开启拼团选项，设置：拼团价格（必须低于原价）、最低拼团人数（2-10人）、拼团有效期（1-7天）
2. 买家在商品详情页可选择"发起拼团"或"加入拼团"
3. 发起拼团后生成拼团订单，状态为"拼团中"
4. 其他买家可查看进行中的拼团并选择加入
5. 达到最低人数后拼团成功，所有参与者以拼团价成交
6. 超过有效期未成团则自动失败，拼团取消

**拼团状态流转：**
- 拼团中 → 拼团成功（达到人数） → 交易中 → 已完成
- 拼团中 → 拼团失败（超时未成团）

**异常处理：**
- 拼团期间卖家不可下架该商品
- 拼团失败后参与者无需额外操作
- 同一用户不可重复加入同一拼团
- 拼团发起人可在未满员时取消拼团

**AI 实现边界：**
- ✅ 必须实现：拼团创建、加入拼团、拼团状态管理、拼团成功/失败处理、拼团倒计时
- ✅ 必须实现：商品详情页拼团入口、拼团列表展示、拼团进度展示
- ❌ 不得实现：拼团分享到外部平台（微信/QQ等）
- ❌ 不得实现：阶梯拼团（不同人数不同价格）
- ❌ 不得实现：拼团自动匹配（仅支持手动加入）
- ⚠️ 需确认后实现：拼团即将到期提醒通知

**验收条件（AC）：**
- [ ] AC-1：卖家可为商品设置拼团价格和最低人数
- [ ] AC-2：买家可成功发起拼团
- [ ] AC-3：其他买家可加入进行中的拼团
- [ ] AC-4：达到最低人数后拼团状态自动变为成功
- [ ] AC-5：超过有效期未成团自动标记为失败
- [ ] AC-6：拼团成功后所有参与者以拼团价成交

## 3. 非功能需求

### 3.1 性能要求

| 指标 | 要求 | 备注 |
|------|------|------|
| 页面加载时间 | ≤ 2秒 | 移动端首屏 |
| API 响应时间 | ≤ 500ms | 95th 百分位 |
| 并发用户数 | 500+ | 校园规模 |
| 数据量级 | 万级商品 | 初期预估 |

### 3.2 安全要求

- 用户密码使用 bcrypt 加密存储
- API 使用 JWT 进行身份认证
- 所有用户输入进行 XSS 和 SQL 注入防护

### 3.3 兼容性要求

- 支持 Chrome、Safari 移动端浏览器
- 响应式设计，适配 320px-768px 屏幕宽度

### 3.4 可用性要求

- 系统可用性目标 99%
- 数据库每日备份

## 4. 业务规则

> **⚠️ AI 约束：以下业务规则优先级高于 AI 的默认判断。若代码逻辑与业务规则冲突，以业务规则为准。**

| 编号 | 规则名称 | 规则描述 | 适用场景 |
|------|----------|----------|----------|
| BR-01 | 实名交易 | 未完成校园邮箱认证的用户不能发布商品和发起交易 | 用户管理、交易管理 |
| BR-02 | 图片限制 | 商品图片最多5张，单张≤2MB，仅支持 jpg/png | 商品管理 |
| BR-03 | 自评禁止 | 用户不能购买自己发布的商品 | 交易管理 |
| BR-04 | 拼团价格约束 | 拼团价格必须低于商品原价且不低于原价的50% | 拼团购买 |
| BR-05 | 拼团人数约束 | 拼团最低人数为2人，最高为10人 | 拼团购买 |
| BR-06 | 拼团有效期约束 | 拼团有效期为1-7天，超时未成团自动取消 | 拼团购买 |
| BR-07 | 拼团库存约束 | 卖家开启拼团时需确保库存数量≥最低拼团人数 | 拼团购买 |
| BR-08 | 拼团唯一性 | 同一用户不可重复加入同一拼团 | 拼团购买 |

## 5. 数据需求

### 5.1 核心数据实体

| 实体名称 | 关键属性 | 说明 |
|----------|----------|------|
| User | id, email, nickname, password_hash, avatar, credit_score, verified | 用户信息 |
| Product | id, seller_id, title, description, price, category, condition, status, images, group_buy_enabled, group_buy_price, group_buy_min_count, group_buy_duration | 商品信息（含拼团设置） |
| Order | id, buyer_id, product_id, status, created_at | 交易订单 |
| Message | id, sender_id, receiver_id, content, type, created_at | 聊天消息 |
| Review | id, order_id, reviewer_id, reviewee_id, rating, comment | 评价信息 |
| GroupBuy | id, product_id, initiator_id, min_count, current_count, group_price, status, expire_at, created_at | 拼团信息 |
| GroupBuyMember | id, group_buy_id, user_id, joined_at | 拼团参与者 |

### 5.2 数据流向概述

- 用户注册 → User 表
- 发布商品 → Product 表（含拼团配置）
- 发起拼团 → GroupBuy 表 + GroupBuyMember 表
- 加入拼团 → GroupBuyMember 表（current_count +1）
- 拼团成功 → 为每个成员生成 Order 记录
- 交易完成 → Review 表

## 6. 界面需求（概要）

### 页面：首页

- **用途：** 展示商品分类和推荐列表
- **核心元素：** 搜索栏、分类导航、商品卡片列表、拼团专区入口
- **关键交互：** 点击分类切换商品列表，点击商品进入详情

### 页面：商品详情页

- **用途：** 展示商品完整信息，提供购买和拼团入口
- **核心元素：** 图片轮播、价格（原价+拼团价）、商品描述、卖家信息、购买按钮、拼团按钮、进行中的拼团列表
- **关键交互：** 点击"立即购买"发起普通交易；点击"发起拼团"创建新拼团；点击"加入拼团"加入已有拼团

### 页面：拼团详情页

- **用途：** 展示拼团进度和参与者信息
- **核心元素：** 拼团倒计时、当前参与人数/最低人数、参与者头像列表、拼团状态、加入按钮
- **关键交互：** 未满员时可点击加入；显示实时倒计时

### 页面：我的拼团

- **用途：** 用户查看自己参与的所有拼团
- **核心元素：** 拼团列表（按状态分类：拼团中/已成功/已失败）
- **关键交互：** 点击进入拼团详情

### 页面：发布商品页

- **用途：** 卖家发布二手商品
- **核心元素：** 表单（标题、描述、价格、分类、图片上传、拼团设置开关及配置项）
- **关键交互：** 开启拼团开关后展示拼团价格、最低人数、有效期设置项
