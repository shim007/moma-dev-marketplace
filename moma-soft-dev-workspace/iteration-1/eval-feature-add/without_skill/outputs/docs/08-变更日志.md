## 2. 变更规则

> **⚠️ AI 约束：以下任何一种情况发生时，必须先记录变更，再执行修改。不得先改代码后补记录。**

**必须记录变更的场景：**
- 需求新增、修改或删除
- 技术架构调整（如更换技术栈组件）
- 数据模型变更（新增/修改表或字段）
- API 接口变更（路径/参数/响应结构变化）

- 重大缺陷修复

**变更审批流程：**
```
提出变更 → 影响评估 → [人工确认] → 更新相关文档 → 执行变更 → 验证
```

## 3. 变更记录

### CR-001: 新增拼团购买功能

| 字段 | 内容 |
|------|------|
| 变更编号 | CR-001 |
| 变更日期 | 2025-07-17 |
| 变更类型 | 需求变更 |
| 影响范围 | 商品模块、订单模块、支付模块、用户中心模块；新增拼团模块 |
| 变更原因 | 业务需求：允许多个用户拼团购买同一商品以获得折扣价，提升平台交易活跃度 |
| 变更内容 | 1. 新增拼团活动管理功能（卖家创建拼团活动）<br>2. 新增拼团发起/参与流程（买家拼团购买）<br>3. 新增拼团状态自动管理与到期处理（定时任务）<br>4. 新增拼团分享功能<br>5. 新增"我的拼团"用户中心页面<br>6. 新增 3 张数据表：group_buy_activity、group_buy_team、group_buy_member<br>7. 新增拼团相关 API 接口 9 个 |
| 影响评估 | - 需新增拼团模块，不影响现有核心交易流程<br>- 订单模块需扩展支持"拼团订单"类型<br>- 支付模块需支持拼团失败退款场景<br>- 数据库需新增 3 张表及相关索引<br>- 预计开发工期：2-3 周 |
| 关联文档更新 | 02-产品需求文档.md、04-数据模型文档.md、05-API接口文档.md |
| 状态 | 已执行 |

### V1.1 - 拼团购买功能

**新增功能：**
- 卖家可为商品创建拼团活动（设置拼团价、目标人数、有效期）
- 买家可发起或参与拼团，拼团价购买商品
- 拼团人数达标自动成团，到期未满自动退款
- 拼团进度实时展示（当前人数/目标人数、倒计时）
- 拼团分享链接生成
- "我的拼团"用户中心页面

**问题修复：**
- 无

**变更：**
- 订单模块扩展支持拼团订单类型
